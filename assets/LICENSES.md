# Third-party assets used in the SVGs

All fonts and icons are embedded (base64) inside each SVG, so nothing is loaded from the network.

- **Bebas Neue**: Copyright Dharma Type (Ryoichi Tsunekawa). https://github.com/dharmatype/Bebas-Neue
- **JetBrains Mono**: Copyright 2020 The JetBrains Mono Project Authors. https://github.com/JetBrains/JetBrainsMono
- **Barlow**: Copyright 2017 The Barlow Project Authors. https://github.com/jpt/barlow

Full license text: https://openfontlicense.org/open-font-license-official-text/

## Brand icons
Icon paths come from **Simple Icons** (CC0 1.0): https://simpleicons.org
- HTML5, CSS, JavaScript, Python, PHP, MySQL, Node.js, React, GitHub, Gmail: `simple-icons` 16.36.0 (npm).
- LinkedIn: no longer in recent Simple Icons releases, so the mark was taken from `simple-icons` 13.21.0 (npm), the last release that includes it.
- Python, PHP, MySQL, CSS, Node.js and LinkedIn colours are lightened slightly for contrast on the dark background.

Brand names and logos are trademarks of their respective owners and are used only to label technologies and links.

## Images
`id.png` and `right_pointing.png` are the owner's own stylized portraits. They are cropped and downscaled (alpha preserved) and embedded in the SVGs; no redrawing.
